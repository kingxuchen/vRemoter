# Permission Guide Screenshots

The app bundles these screenshots for its permission guides:

- `permission-microphone.png`: Privacy & Security > Microphone
- `permission-accessibility.png`: Privacy & Security > Accessibility
- `permission-input-monitoring.png`: Privacy & Security > Input Monitoring
- `permission-bluetooth.png`: Privacy & Security > Bluetooth

The red callout is drawn by the app at runtime. To refresh a guide after a
macOS UI change, replace the corresponding PNG with a screenshot of the same
settings page and keep the filename unchanged.
